# Changelog

## 0.6.0 — 2026-09-10

- **Personal vocabulary**: technical terms are no longer spelled
  phonetically ("MLX" -> "Meleiks"). Terms come from
  `~/.config/parlando/vocabulary.txt` (one per line) and/or `--vocab
  "MLX, PyPI"`, are injected into Qwen3-ASR's system prompt (context
  biasing), hinted to the polish LLM, and exempted from the polish
  guard's novel-word check so spelling corrections survive it.
- Record mode gained a deterministic energy gate: a recording with no
  speech-level audio never reaches the ASR (on silence the model
  hallucinates — with a vocabulary in context it parrots those terms).
- Vocabulary is editable from the menu bar (Vocabulary → Add Term… /
  Edit Vocabulary File…) and hot-reloads on file change — edits are
  live at the next recording, no restart.

## 0.5.0 — 2026-09-09

- **`Parlando.app`**: `parlando --install-app` generates a thin,
  ad-hoc signed app bundle in `~/Applications` (Info.plist, app icon, a
  prebuilt Mach-O stub that runs a launch script for the installed
  package). Launched from Finder/Spotlight or the login item, Microphone
  and Accessibility permissions are requested and stored as "Parlando"
  instead of the terminal that happened to start it. `--uninstall-app`
  removes it; `--install-login` now starts the app bundle.
- Accessibility check now triggers the macOS prompt itself
  (`AXIsProcessTrustedWithOptions`) and the warning states that the
  hotkey is silent without the permission, not only typing. The menu bar
  app shows this as a dialog. While the permission is missing parlando
  re-checks every 2 s and, once granted, re-creates the hotkey listener
  itself: no restart after flipping the switch. macOS may terminate the
  app at that moment; while the permission is missing, `Parlando.app`
  arms a launchd relaunch guard that reopens it automatically (removed on
  a normal quit and once the permission is in place).
- New macOS app icon (`Parlando.icns`, `assets/app-icon.png`) from
  `scripts/make_icons.py`; `scripts/launcher.c` + `build_launcher.sh`
  for the stub.
- **Status in the menu bar.** The menu opens with a status block: what
  parlando is doing (starting, downloading the model with percentage and
  size, loading, ready, recording with elapsed seconds, transcribing,
  paused), a hint line, and, when something needs you, a one-click "Open
  … settings" line. A small badge next to the icon shows it without
  opening the menu (`52%`, `…`, `!`, `✎`). Model downloads now report
  progress in the terminal too. Recording is disabled until ready.
- The microphone check is recoverable: a silent mic shows as a problem,
  the audio stream is reopened every 5 s so a permission granted after
  start is picked up, and the first real audio clears it.
- Requires Python 3.11+ (`onnxruntime` no longer ships 3.10 wheels);
  `install.sh` installs from PyPI; `ruff` configured and run in CI.
- Experimental `scripts/build_app.sh`: a self-contained `Parlando.app` +
  `.dmg` with a relocatable CPython and all dependencies embedded (~250 MB
  compressed; the ASR model still downloads on first run), plus
  `scripts/make_signing_cert.sh` for a stable self-signed signing identity.
  Not the supported distribution: install with `uv` (see README).

## 0.4.2 — 2026-09-09

- **`parlando` opens the menu bar app.** The terminal mode moved behind
  `--terminal` / `-t` (implied by `--pipe`); terminal-only options given
  without it are rejected with a hint instead of being ignored.
  `--install-login` / `--uninstall-login` work on the main command and the
  login item now runs `parlando`. `parlando-menubar` stays as an alias.
- **Turkish is the default language** (`--language English` for English).
  Voice commands and filler cleanup follow the language; the menu bar
  badge now marks a non-default language (ᵉⁿ) instead of Turkish.

## 0.4.1 — 2026-09-09

- README images now use absolute URLs so the banner and menu bar icon
  strip render on PyPI (relative paths only resolve on GitHub).

## 0.4.0 — 2026-09-09

- **Cleanup**: unambiguous vocalized fillers (um, uh, eee, ııı) are removed
  deterministically per language (`--no-cleanup` to keep them); stutter
  runs of 3+ identical words collapse to one.
- **Polish (`--polish`)**: optional local-LLM cleanup at finalize — drops
  contextual fillers, stutters and false starts, fixes punctuation. Guarded
  so the LLM can only edit the transcript, never answer or extend it
  (falls back to the raw text otherwise). Default model Qwen3-1.7B-4bit
  (10/11 on the built-in benchmark, ~0.4 s); Qwen3-4B-4bit scores 11/11.
- New `scripts/eval_polish.py`: 11-case cleanup benchmark (fillers,
  stutters, false starts, adversarial answer/injection guards, identity)
  that runs against the real local LLM.
- Brand assets: custom template menu bar icons (three-bar speech waveform)
  and a README banner, generated by `scripts/make_icons.py`.

## 0.3.1 — 2026-09-08

- Restructured into a proper Python package (`src/parlando/`, hatchling,
  `pyproject.toml`) with `parlando` and `parlando-menubar` entry points.
- `install.sh` now uses `uv tool install` (uninstall with
  `uv tool uninstall parlando`); start-at-login uses the installed command.
- CI additionally validates the packaging build (`uv build`).
- PyPI publication intentionally deferred; `uvx parlando` will work once
  published.

## 0.3.0 — 2026-09-08

- Project renamed to **parlando**; full internationalization (all code,
  CLI, menu bar, and docs in English).
- Language-aware voice commands: English set by default, Turkish set with
  `--language Turkish`.
- `--version` flag; log moved to `~/Library/Logs/parlando.log`.
- Repository prepared for open-source release (license attribution,
  upstream site assets removed, English README, CI badge).

## 0.2.0 — 2026-09-08

- **Record mode (default)**: tap-speak-tap; the whole recording is
  transcribed once and typed in one go. Long recordings split at silence.
- Global hotkey: single tap of right Option (chord-aware), configurable.
- Menu bar app (rumps) with start/stop, language switching, Enter mode,
  and `--install-login` LaunchAgent.
- Quartz CGEvent unicode typing with osascript fallback.
- Audio-stream watchdog (sleep/device-change recovery); microphone and
  Accessibility permission diagnostics; file logging.
- Streaming stability: normalized LocalAgreement, stall safety valve,
  asymmetric noise-floor learning (deafness fix), guarded event loop.
- Optional hybrid Silero VAD (`--silero`); voice commands; 35 unit tests
  and macOS CI.

## 0.1.0 — 2026-09-08

- Initial utterance-based dictation engine on top of the dictate.sh
  Qwen3-ASR MLX engine: energy VAD, append-only word commits with
  LocalAgreement-2, hallucination guards, safe peak normalization.
